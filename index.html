كيف تذاكر Ansible وتتقنه بنسبة 100%؟

تُعد أداة Ansible (من شركة Red Hat) المعيار الذهبي في Configuration Management وأتمتة الخوادم والشبكات والسحابات. تتميز بأنها Agentless (بدون تثبيت أي عميل على السيرفرات المستهدفة)، وتعتمد على مبدأ Idempotency (التكرار الآمن دون تغيير غير ضروري) عبر بروتوكول SSH أو WinRM أو Cloud APIs. بينما ينشئ Terraform البنية التحتية، يقوم Ansible بتهيئة السيرفرات ونشر التطبيقات وتأمين الأنظمة!

الرسوم البصرية: المعمارية بدون عميل (Agentless Architecture)

⚡محاكي دورة عمل Ansible والـ Idempotency (Push Execution Engine)

شغّل خطوات تنفيذ Playbook خطوة بخطوة، وشاهد كيف يتصل الـ Control Node بالسيرفرات عبر SSH، ويجمع الـ Facts، ويحقق الـ Idempotency (الأخضر OK، الأصفر CHANGED، البرتقالي HANDLER)!

المرحلة الحالية: 1. قراءة الـ Inventory وملف ansible.cfg اضغط على أي عقدة في الرسم أو أزرار الأوامر بالأعلى

ماذا يحدث داخلياً في هذه الخطوة؟

يبدأ Ansible بقراءة ملف الإعدادات `ansible.cfg` لتحديد عدد العمليات المتوازية (`forks = 5` افتراضياً)، ثم يقرأ قائمة السيرفرات المستهدفة من الـ Static أو Dynamic Inventory ويجمع المتغيرات (`group_vars` و `host_vars`).

💡 نصيحة: فعّل `pipelining = True` في ansible.cfg لتسريع تنفيذ المهام عبر SSH بشكل ملحوظ!
bash — ansible-playbook ● agentless-ssh 
$ ansible-inventory -i inventory/prod.yml --graph
@all:
  |--@webservers:
  |  |--web-01.prod.local
  |  |--web-02.prod.local
